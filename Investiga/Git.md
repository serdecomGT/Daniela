#GIT
##¿QUÉ ES GIT?
Git es un sistema de control de versiones utilizado principalmente por programadores para guardar, organizar y controlar los cambios que se realizan en un proyecto de software.
Fue creado por Linus Torvalds en 2005, el mismo desarrollador conocido por crear el núcleo de Linux. Git permite conservar diferentes versiones de un proyecto, de manera que si se comete un error se puede revisar el historial y regresar a una versión anterior.

##¿PARA QUÉ SE USA?
Guardar diferentes versiones de un proyecto.

Controlar los cambios realizados en los archivos.

Trabajar en equipo sin sobrescribir fácilmente el trabajo de los demás.

Volver a versiones anteriores cuando algo sale mal.

Crear ramas (branches) para trabajar en nuevas funciones sin modificar directamente el proyecto principal.

Unir cambios realizados por diferentes personas.

Registrar quién hizo cada cambio y cuándo lo hizo.

Trabajar en proyectos de programación, páginas web, aplicaciones y otros tipos de software.

##¿PARA QUÉ SE USA?
Git guarda un historial de los cambios mediante commits. Un commit es como una "fotografía" del proyecto en un momento determinado.

Después haces otros cambios y creas otro commit. Así Git va construyendo un historial que permite saber cómo ha evolucionado el proyecto.

También existen las ramas o branches, que permiten crear una versión independiente del proyecto para experimentar o desarrollar una función nueva. Cuando termina, los cambios pueden integrarse nuevamente a la rama principal.

##¿QUÉ TIENE DE INTERESANTE GIT?
Una de las cosas más interesantes es que Git funciona de manera distribuida. Esto significa que cada persona que descarga o clona un proyecto puede tener una copia completa de su historial. No depende de que todo el historial esté únicamente en un servidor central.
Además, Git permite que varias personas trabajen simultáneamente en un mismo proyecto. Por ejemplo, una persona puede trabajar en el diseño de una página, otra en el sistema de inicio de sesión y otra en una base de datos, y posteriormente pueden combinar sus cambios.

**DATOS CURIOSOS SOBRE GIT**
Git fue creado en 2005 por Linus Torvalds, quien necesitaba una herramienta para gestionar el desarrollo del kernel de Linux.
El nombre "Git" es bastante particular. Torvalds utilizó el nombre de manera humorística y existen varias interpretaciones sobre su significado.
Git es gratuito y de código abierto.
Aunque Git y GitHub suelen mencionarse juntos, no son lo mismo. Git es el sistema de control de versiones, mientras que GitHub es una plataforma que permite alojar y colaborar con repositorios Git.
Git puede utilizarse sin conexión a Internet para realizar muchos de sus procesos, porque el historial se encuentra en el equipo.
Es utilizado en proyectos pequeños realizados por estudiantes y también en proyectos enormes desarrollados por miles de personas.
Git puede trabajar no solamente con código, sino prácticamente con cualquier tipo de archivo, aunque funciona especialmente bien con archivos de texto.

**LO NEGATIVO DE GIT**
Aunque es muy útil, Git puede resultar complicado para principiantes, especialmente cuando se empiezan a utilizar ramas, fusiones (merges) y comandos más avanzados. También es posible cometer errores si se utilizan comandos sin comprender qué hacen.
En resumen: Git es una herramienta fundamental para el desarrollo de software porque permite controlar, organizar y recuperar las diferentes versiones de un proyecto, facilitando especialmente el trabajo colaborativo.
