## Sección A — Conocimientos generales

1. ¿Qué es Markdown y para qué fue creado?
Markdown es un lenguaje de marcado que permite dar formato a textos de manera sencilla. Fue creado para escribir documentos fáciles de leer y convertirlos a HTML.

2. ¿Quién creó Markdown y en qué año aproximadamente?
Fue creado por John Gruber, con la colaboración de Aaron Swartz, aproximadamente en 2004.

3. ¿Markdown es un lenguaje de programación, un lenguaje de marcado o un lenguaje de estilos? Justifica tu respuesta.
Es un lenguaje de marcado, porque utiliza símbolos para estructurar y dar formato al contenido, pero no sirve para programar.

4. Menciona al menos tres plataformas o herramientas donde se utiliza Markdown de forma habitual.
GitHub, Reddit y Discord.

## Sección B — Sintaxis básica

5. ¿Cómo se escribe un título de nivel 1, nivel 2 y nivel 3 en Markdown?
#Título 1
##Título 2
###Título 3

6. ¿Cuál es la diferencia entre usar `**texto**` y `*texto*`?
** texto ** aparece en negrita y * texto * aparece en cursiva.

7. Escribe en Markdown una lista con tres elementos que sean viñetas (no numerada).
- Manzana
- Pan
- Leche

8. Escribe en Markdown una lista numerada con tres pasos para preparar un café.
1. Calentar el agua.
2. Agregar el café.
3. Servir y endulzar.

9. ¿Cómo se inserta un enlace (hipervínculo) en Markdown? Proporciona un ejemplo.
[Google](https://www.google.com)

10. ¿Cómo se inserta una imagen en Markdown? ¿En qué se diferencia de insertar un enlace?
![Descripción de la imagen](imagen.jpg)
La imagen se muestra directamente, mientras que el enlace sirve para dirigir a otra página o recurso.

## Sección C — Uso práctico en GitHub

11. ¿Qué archivo Markdown es el más importante en un repositorio de GitHub y qué función cumple?
El archivo README.md, porque explica de qué trata el proyecto, cómo utilizarlo y otra información importante.

12. ¿Cómo se inserta un bloque de código en Markdown? Muestra un ejemplo con y sin especificar el lenguaje.

```

```

14. ¿Puedes usar HTML dentro de un archivo Markdown? Da un ejemplo de cuándo sería útil.

15. ¿Qué extensión de archivo tiene un documento Markdown?
Generalmente .md.

## Sección D — Pregunta reflexiva

16. ¿Por qué crees que GitHub y muchas comunidades técnicas prefieren Markdown sobre otros formatos como Word o PDF para documentar proyectos?
Porque es sencillo, ligero, fácil de editar y funciona muy bien en diferentes plataformas. Además, permite organizar textos, código, imágenes y enlaces sin necesitar programas especiales.
